# Guanaco ShareGPT

Original [Guanaco dataset](https://hf.co/timdettmers/openassistant-guanaco) has been used a lot for fine tuning models and making proof-of-concept systems. The dataset dates back to when there was basically no standardized version of a chat template and even us, used the original format on [MaralGPT](https://hf.co/MaralGPT). 

Recently, while working on a finetune using [Unsloth](https://unsloth.ai) I noticed that there are tons of possible ways of making the chat template more efficient. The code in this repo resulted in [Muhammadreza/Guanaco-ShareGPT](https://Muhammadreza/Guanaco-ShareGPT) which is my version of this dataset.
